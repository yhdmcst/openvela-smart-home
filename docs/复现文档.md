## 1. 环境要求

### 1.1 硬件要求

| 项目 | 最低配置 | 推荐配置 |
|------|----------|----------|
| CPU | 4 核心 | 8 核心以上 |
| 内存 | 8 GB | 16 GB |
| 磁盘 | 50 GB 空闲 | 100 GB SSD |
| 网络 | 宽带（需下载约20GB源码） | - |

### 1.2 软件要求

| 软件 | 版本 | 说明 |
|------|------|------|
| Ubuntu | 22.04 LTS (x86_64) | 必须 |
| Git | 2.34+ | 通过 apt 自动安装 |
| Python3 | 3.10+ | 通过 apt 自动安装 |
| CMake | 3.22+ | 通过 apt 自动安装 |
| QEMU | 6.2+ | 通过 apt 自动安装 |
| repo | 最新 | 脚本自动安装 |

### 1.3 环境检测命令

```bash
# 确认系统版本
lsb_release -a

# 确认架构
uname -m              # 应输出 x86_64

# 确认可用空间

```

## 2. LLM 后端配置步骤

### 2.1 选择并配置 LLM 后端

```bash
# 运行 LLM 切换脚本
./switch_llm.sh

# 选择：
# 1) DeepSeek    - 推荐（国内访问快）
# 2) 通义千问     - 免费额度多
# 3) Ollama 本地  - 无需联网
```

### 2.2 配置 API Key（必须！）

```bash
# 编辑配置文件
vim openvela_workspace/packages_ai_agent/config/llm_config.h

# DeepSeek: 将 YOUR_DEEPSEEK_API_KEY 替换为真实 Key
#   获取地址: https://platform.deepseek.com/api_keys

# 通义千问: 将 YOUR_DASHSCOPE_API_KEY 替换为真实 Key
#   获取地址: https://dashscope.console.aliyun.com/apiKey

# Ollama: 无需 API Key，但需先拉取模型
#   ollama pull qwen2.5:7b
```

### 2.3 测试 API 连通性

```bash
./switch_llm.sh test
```

```bash

    build-essential git-lfs gcc-aarch64-linux-gnu g++-aarch64-linux-gnu \

bash build_vela_arm64.sh
```

## 4. 常见异常处理

### 4.1 repo sync 失败 / 网络超时

```
现象：error: Cannot fetch ... 或 RPC failed
原因：GitLink 或 GitHub 连接不稳定

解决：
1. 配置 Git 代理（如果有）
   git config --global http.proxy http://127.0.0.1:7890
   git config --global https.proxy http://127.0.0.1:7890

2. 增加 Git 缓冲区
   git config --global http.postBuffer 524288000

3. 使用国内镜像（如果配置了）
   export REPO_URL='https://mirrors.tuna.tsinghua.edu.cn/git/git-repo'
```

### 4.2 编译内存不足

```
现象：virtual memory exhausted: Cannot allocate memory
原因：编译并行任务太多，内存不够

解决：
1. 减少并行编译数
   make -j2  # 改为2线程

2. 增加 swap 空间
   sudo fallocate -l 8G /swapfile
   sudo chmod 600 /swapfile
   sudo mkswap /swapfile
   sudo swapon /swapfile
```

### 4.3 QEMU 启动失败

```
现象：qemu-system-aarch64: Invalid parameter
原因：可能是 QEMU 版本过低

解决：
1. 检查 QEMU 版本
   qemu-system-aarch64 --version  # 需 >= 6.2

2. 升级 QEMU
   sudo apt-get install -y qemu-system-arm qemu-system-aarch64

3. 手动指定内核
   ./start_simulator.sh --kernel /path/to/nuttx
```

### 4.4 Tool 注册失败

```
现象：[ToolRegistry] 智能家居Tool模块初始化失败
原因：smart_home_tools_init() 未找到

解决：
1. 确认 tool_*.c 文件位置
   find openvela_workspace -name "tool_light_control.c"

2. 手动复制到正确位置
   cp tools/tool_light_control.c openvela_workspace/packages_ai_agent/tools/
   cp tools/tool_temperature_read.c openvela_workspace/packages_ai_agent/tools/

3. 重新编译
   cd openvela_workspace && bash build_vela_arm64.sh
```

### 4.5 LLM API 连接失败

```
现象：[LLM] Connection timeout / 401 Unauthorized
原因：API Key 未配置或网络不通

解决：
1. 检查 API Key 是否正确配置
   grep "LLM_API_KEY" openvela_workspace/packages_ai_agent/config/llm_config.h

2. 测试网络联通
   curl -I https://api.deepseek.com

3. 如在国内访问 DeepSeek 慢，切换通义千问
   ./switch_llm.sh qwen
```
